# 过拟合实验指南

## 📋 实验目的

通过充分过拟合的训练配置，学习：
1. **过拟合的含义**：模型过度记忆训练数据，导致泛化能力下降
2. **各参数的作用**：不同超参数如何影响过拟合程度
3. **指标对比**：训练集指标 vs 验证集指标的差异

### 2. 各参数的作用理解

#### LEARNING_RATE (5e-6)
- **作用**: 更小的学习率 = 更精细的参数调整
- **效果**: 模型可以更精确地记忆训练数据的细节
- **过拟合影响**: ⭐⭐⭐ (中等)

#### NUM_TRAIN_EPOCHS (20.0)
- **作用**: 更多训练轮数 = 更多机会记忆训练数据
- **效果**: 模型有足够时间完全记忆训练集
- **过拟合影响**: ⭐⭐⭐⭐⭐ (最强)

#### LORA_DROPOUT (0.0)
- **作用**: 关闭dropout = 模型可以完全记忆，不受随机性干扰
- **效果**: 训练时和推理时行为一致，完全记忆训练数据
- **过拟合影响**: ⭐⭐⭐⭐ (很强)

#### WEIGHT_DECAY (0.0)
- **作用**: 关闭权重衰减 = 参数可以自由增长，不受L2正则化约束
- **效果**: 模型参数可以变得很大，完全拟合训练数据
- **过拟合影响**: ⭐⭐⭐ (中等)

#### LORA_RANK (128)
- **作用**: 更高的rank = 更多可训练参数 = 更强的表达能力
- **效果**: 模型有足够容量记忆所有训练样本
- **过拟合影响**: ⭐⭐⭐⭐ (很强)

#### LR_SCHEDULER_TYPE ("constant")
- **作用**: 恒定学习率 = 持续学习，不衰减
- **效果**: 即使训练后期也能继续调整参数，持续记忆
- **过拟合影响**: ⭐⭐ (较弱)

## 🎓 学习要点总结

### 过拟合的含义
1. **定义**: 模型过度记忆训练数据，导致在训练集上表现很好，但在新数据上表现差
2. **表现**: 训练集指标高，验证集指标低，两者差距大
3. **原因**: 模型学习了训练数据的噪声和特定模式，而不是通用的规律

### 各参数的作用
1. **正则化参数** (dropout, weight_decay): 防止过拟合
2. **模型容量** (lora_rank): 容量越大，越容易过拟合
3. **训练轮数** (num_train_epochs): 训练越久，越容易过拟合
4. **学习率** (learning_rate): 学习率越小，拟合越精细，越容易过拟合

### 如何防止过拟合
1. **增加正则化**: dropout > 0, weight_decay > 0
2. **减少模型容量**: 降低 lora_rank
3. **早停机制**: 监控验证集指标，提前停止
4. **数据增强**: 增加训练数据的多样性
5. **交叉验证**: 使用多个验证集
